Red Dragon Factory — Unified Feasibility Study System

Plan Document  |  Created: June 3, 2026  |  Status: Approved by User

1. Goal

Combine the best features from all three existing projects into one unified system that covers investment planning, sales-driven production planning, product catalog management, labor capacity analysis, salary model comparison, and profitability decisions.

2. Architecture

Multi-file modular setup using vanilla JavaScript ES modules. No build step. No framework.

FilePurpose
index.htmlEntry point (open with Live Server)
css/styles.cssComplete dark-theme design system
js/data.js60 products, 11 employees, default state
js/i18n.jsAll UI text in English + 中文
js/engine.jsPure math: production plan, payroll, profit
js/state.jsState management, localStorage, JSON/Excel I/O
js/ui.jsShared helpers: formatting, DOM builders
js/charts.jsChart.js wrappers (donut, bar, line)
js/tabs/*.jsOne file per tab (7 tabs)
js/app.jsMain controller, header, rail, events

Tech stack: Plain ES modules. Chart.js and SheetJS loaded from CDN. Requires a local web server (VS Code Live Server or python -m http.server).

3. The 7 Tabs

Tab 0 — Overview

  • 4 Hero KPI cards: Monthly Sales, Material Cost, Payroll, Net Profit (color-coded)
  • Scenario table: Worst / Base / Best columns showing Sales, Material, Payroll per model, Net, Margin %
  • Accuracy check: Reconciles to documented 6-month actuals — ¥2,017,193 sales · ¥1,031,503 material · ¥399,152 net
  • Quick actions: Reconcile to base · Reset · Export · Import

Tab 1 — Investment & Allocation

  • Total Investment input with Auto-calculate toggle
  • Auto formula: rent×3 + electric×3 + payroll×3 + ¥200k + ¥100k + ¥100k
  • Editable allocation buckets (Fixed or Months × Basis)
  • Chart.js donut chart for budget breakdown
  • Summary: Total needs · Surplus/Shortfall · Reserve cash · Burn at zero · Runway
  • Verdict: "ENOUGH TO START" or "NOT ENOUGH YET"

Tab 2 — Sales → Production Plan

  • Sales control rail: slider + big number + Worst/Base/Best presets
  • Flex ±% to adjust scenario range
  • Production table: Group/Item · Mix % · Qty to produce · Revenue · Material · Labor hours
  • Quantities scale from historical 6-month revenue mix
  • Chart.js bar chart: Revenue by group

Tab 3 — Products & Data

  • 9 Group summary cards with items count, produced count, annual sales, missing prices
  • Per-group editable tables: Raw cost · Labor hours · Annual qty · Price USD · Price CNY · Annual revenue
  • Red flags on missing prices for items with qty > 0
  • Add item · CSV template · CSV import · "Only produced" filter

Tab 4 — Labor Capacity

  • Inputs: Hours/day · Days/month
  • KPIs: Utilization % · Shortfall/Headroom · Capacity ceiling
  • Workforce table: Name · Position · Type · Basic salary · Hours/mo
  • Chart.js stacked bar: Utilized / Overtime / Available
  • Verdict: "ADEQUATE" / "TIGHT" / "INSUFFICIENT"

Tab 5 — Salary Model Lab (Centerpiece)

  • 5 Model tabs: 0·Fixed | A·Profit-share | B·Stepped | C·Commission | D·Custom
  • Dynamic model description
  • Tune: Basic % · Reference sales S₀ · Accelerator target & multiplier · Custom weights
  • Editable roster: Name · Position · Group · Current · Basic (floor) · Hours/mo · Calculated pay
  • Owner View: Side-by-side model comparison + payroll-vs-sales line chart
  • Employee View: Today vs New · Delta · "Sales to match today's pay" per person

Tab 6 — Costs & Decision

  • Fixed cost inputs: Rent/mo · Electricity/mo
  • Chart.js donut: Materials · Salaries · Rent · Electricity
  • Profit waterfall: Sales → −Material → −Payroll → −Rent/Elec = Net
  • Projection: Net × months
  • Two verdicts: "PROFITABLE?" + "INVESTMENT ENOUGH?"
  • Ground-truth 6-month reconciliation

4. Global Controls

  • Sticky Header: Brand · Language (EN/中文) · Currency (CNY/USD) · Exchange rate · Months · Buttons · Saved dot
  • Sticky Rail: Scenario buttons · Sales slider · Sales number · Base monthly · Flex %

5. The 5 Salary Models (Formulas)

ModelNameFormula
M0Fixedpay = current salary (baseline)
AProfit-sharepay = basic + (current−basic) × (sales/S₀) × accel
BSteppedpay = basic + (current−basic) × tierMultiplier — jumps at sales thresholds
CCommissionpay = basic + commissionPool × (gap/totalGap)
DCustomBlend of A + C with adjustable weights

All models floor at basic salary. At sales = S₀, every variable model ≈ today's salary.

6. Import / Export / Persistence

  • Auto-save: localStorage (400ms debounce)
  • JSON: Export / Import full state
  • Excel (SheetJS): 5 sheets — Products · Employees · Buckets · Fixed Costs · Settings
  • CSV: Template export + bulk product import
  • Reset: Wipes localStorage, restores factory defaults

9. User Flow

  1. Open page → data loads from localStorage or seeds from 6-month actuals
  2. Check Overview → confirms accuracy against real numbers
  3. Go to Investment → enter total (or Auto ON) → see runway
  4. Slide sales target → all tabs update: quantities, materials, hours, payroll, profit
  5. Go to Salary Lab → pick model → tune parameters → see every person's new pay
  6. Go to Costs & Decision → read the two verdicts
  7. Export to Excel → edit → import back
