Red Dragon Factory — Unified Feasibility Study System

Updated Plan Document  |  Created: June 3, 2026  |  Status: Approved by User

1. What the User Asked For

  • Two salary models only: Fixed (baseline) + Ramp & Multiplier (new)
  • Adjustable multiplier inside the app with a slider
  • Sales slider inside the Salary Lab so the user can drag sales up/down and watch salary move in real time
  • Three language modes: English only / 中文 only / English + 中文 together (bilingual labels)
  • Everything editable: All products, employees, prices, hours, costs, buckets, targets, multipliers — every number and name is an inline input

2. Architecture

Multi-file modular setup using vanilla JavaScript ES modules. No build step. No framework.

  • Two model tabs: 0·Fixed | 1·Ramp & Multiplier

  • Tune panel:

4. The Two Salary Models (Final)

Model 0 — Fixed: Everyone gets their Standard salary no matter what sales do. This is today's system. Baseline for comparison.
Model 1 — Ramp & Multiplier:
  • Basic = survival minimum (e.g. 60% of Standard)
  • Standard = full pay at reference sales S₀
  • Below S₀: Pay ramps linearly from Basic up to Standard
  • At S₀: Pay = Standard
  • Above S₀: Pay grows unlimited with the Multiplier you set

Formula:

If Sales ≤ S₀:
  Pay = Basic + (Standard − Basic) × (Sales / S₀)

If Sales > S₀:
  Pay = Standard + (Standard − Basic) × Multiplier × ((Sales − S₀) / S₀)

Example (Standard = ¥10,000, Basic = ¥6,000, S₀ = ¥333,000):

SalesMultiplier = 0.5Multiplier = 1.0Multiplier = 1.5
¥0¥6,000¥6,000¥6,000
¥166k (50%)¥8,000¥8,000¥8,000
¥333k (S₀)¥10,000¥10,000¥10,000
¥500k (1.5×)¥11,000¥12,000¥13,000
¥666k (2×)¥12,000¥14,000¥16,000

  • CSV: Template export + bulk product import

9. User Flow

  1. Open page → data loads from localStorage or seeds from 6-month actuals
  2. Check Overview → confirms accuracy against real numbers (¥2M sales / ¥1M material / ¥399k net)
  3. Go to Investment → enter total (or Auto ON) → see runway months
  4. Slide the main sales target → all tabs update instantly
  5. Go to Salary Lab → switch to Model 1 (Ramp & Multiplier)
  6. Drag the Multiplier slider → watch payroll change, watch profit change
  7. Drag the Sales slider inside the Salary Lab → watch each person's pay go up/down
  8. Set Basic % (e.g. 60%) → click Apply → everyone's basic floor updates
  9. Go to Costs & Decision → read the two verdicts
  10. Export to Excel → edit → import back
